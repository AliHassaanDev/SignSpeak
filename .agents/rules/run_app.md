# Running the Application

Whenever you need to run the application for testing or the user asks you to start the app, always execute the `start.bat` script located in the root directory (`d:\Courses\two-way-psl-translator\start.bat`). 

This script will natively open the command prompt windows for both the backend (FastAPI) and frontend (Next.js) servers so that the user can monitor the logs independently of your background tasks.

**Command to run:**
```powershell
.\start.bat
```
